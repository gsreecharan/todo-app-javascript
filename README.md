# Vanilla JavaScript Task Manager

An interactive task management web application built entirely with vanilla JavaScript, semantic HTML5, and custom CSS3. 

**Live Deployment:** https://gsreecharan.github.io/todo-app-javascript

---

## Overview

This project demonstrates core DOM manipulation and frontend state management without the use of heavy frameworks. It handles dynamic HTML rendering, event delegation, and input validation to provide a seamless user experience for tracking daily tasks.

### Key Features
- **Dynamic DOM Manipulation:** Real-time creation, reading, updating, and deletion (CRUD) of task elements using pure JavaScript.
- **Event Handling:** Utilizes event listeners for user interactions (adding tasks, marking complete, deleting).
- **Input Validation:** Defensive programming to prevent the creation of empty or whitespace-only tasks.
- **Responsive UI:** Clean, accessible interface styled with CSS3 flexbox and grid properties.

---

## Technical Stack

- **Frontend:** Vanilla JavaScript (ES6+)
- **Markup:** HTML5
- **Styling:** CSS3

### Local Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/gsreecharan/todo-app-javascript.git
   cd todo-app-javascript
   ```
2. Open `index.html` directly in any web browser, or launch it using the VS Code Live Server extension.
